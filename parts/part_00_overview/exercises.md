# Part 0 Exercises

## 1. DuckDBを一文で説明する

次の語を使って、DuckDBを一文で説明してください。

- embedded
- OLAP
- SQL
- ファイル

## 2. 使うべきでない場面を選ぶ

次のうちDuckDBをメインDBにしない方がよいものを選び、理由を書いてください。

- ECサイトの注文登録
- CSVをまとめてParquetに変換するバッチ
- Notebookで商品データを集計する作業
- PostgreSQLから読み出したデータの品質チェック

## 3. 比較する

SQLite、PostgreSQL、DuckDBを比較し、それぞれ「得意な処理」を1つずつ書いてください。

## 提出物

- DuckDBの説明文
- 使うべきでない場面と理由
- 3つのDBの比較メモ

## 進級チェック

DuckDBを「アプリのメインDB」ではなく「分析・前処理・ファイル処理のエンジン」として説明できれば合格です。
